# session-summaries(会话摘要目录)

本目录存放每次对话收尾时自动生成的会话摘要,文件名格式:

```
YYYY-MM-DD_session-summary_{topic}.md
```

规则:

- 一次对话一份摘要,只追加不改写;同一天多段短对话合并到当日文件追加章节
- 摘要六段结构:① 用户诉求 ② 已完成产出 ③ 关键决策与约定 ④ 待办与下一步 ⑤ 涉及文件 ⑥ 可入长期记忆的线索
- 断点续接时,助手先读本目录最近 1~2 份摘要再动手
- 详细维护规则见 SKILL.md「记忆沉淀规则」

> 本 README 仅为目录占位说明,技能安装后可保留;摘要文件由助手在使用中自动创建。
