# finance-bp-workflow · 财务 BP 业务逻辑分析技能

> 把「行业/公司业务逻辑拆分」固化成一条标准工作流:七视角分析框架 + 8 模块报告结构 + 指标三层分类(流量/交易/盈利)+ 跨会话记忆库。
> 适用于财务 BP、经营分析、财会转行业分析等场景的行业研究与公司对标。

本技能遵循通用 **Agent Skills(SKILL.md)标准**,可在支持该标准的 AI 助手中安装使用(已验证思路:豆包 PC 版 / 豆包工作;同类产品 WorkBuddy 等同样按 SKILL.md 识别技能)。

## 🚀 安装方法

### 方式一:豆包 PC 版 / 豆包工作(拖入目录)

1. 打开豆包 PC 版,进入「**技能 · 连接器 · 伙伴**」→「**我的技能**」
2. 点击右上角「**新建 → 上传技能**」
3. 把 **`finance-bp-workflow` 整个文件夹**拖入上传区(不是拖单个文件)
4. 等待识别完成,技能出现在「我的技能」中即安装成功

### 方式二:WorkBuddy / 其他支持 SKILL.md 的助手

- 将 `finance-bp-workflow` 文件夹放入该产品的技能目录(常见为 `.agents/skills/` 或应用设置中的「技能/插件」目录),重启或刷新技能列表即可
- 若产品仅支持导入 zip,先把文件夹压缩为 zip 再通过「导入技能」上传

### 方式三:临时使用(不安装)

直接把整个文件夹(或 zip)作为附件发给助手,说:

> 读取这个技能里的 SKILL.md,按其中的工作流帮我分析 XX 行业

## 💡 使用示例

安装后,在对话中直接说自然语言即可触发:

- `帮我拆分一下新能源汽车行业的业务逻辑`
- `用财务 BP 视角分析餐饮行业,重点看利润池和财务三表`
- `对比电商行业拼多多、美团、京东的收入/成本/利润结构差异`
- `这份报告是为面试准备的,按面试场景输出`(规范内置面试场景模式)
- `接着上次的行业分析继续`(助手会先读取会话摘要断点续接)

首次运行时,助手会自动在你的工作目录初始化:`01_分析产出/`(报告)、`02_知识库/`(含种子词库)、`03_模板库/`(含指标模板)。

## 🔧 自定义方法论

技能出厂规范在 `reference/`(只读基准)。想改成自己的分析框架:

1. 让助手把 `reference/` 的 5 份规范复制到工作区 `00_Agent规范/`
2. 在副本上自由修改(章节结构、指标数量、排版规则等)
3. 此后工作区副本优先,助手每次开工自动装载你的版本

## 🔒 隐私说明

- 技能包**不含任何个人记忆**:`memory/` 仅 shipped 空白模板,你的画像、偏好、会话摘要从首次使用开始才在本地生成
- 报告与词库均为通用方法论与公开行业知识,不含任何真实企业内部数据
- 记忆数据保存在本地技能目录(若目录只读则保存在工作区 `.finance-bp-memory/`),不上传任何第三方
